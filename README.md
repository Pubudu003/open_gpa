# OPEN GPA (GPA Calculator v2.0)

## ✨ Features

### 🔐 Authentication

- User registration
- Email verification
- Password reset

### 👤 Student

- Select degree
- Change degree
- Select courses
- Select grade
- View calculated GPA
- Manage courses
- Send feedback

### 👨‍💼 Admin

- Manage degrees
- Manage courses
